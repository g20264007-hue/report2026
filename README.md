# 시간과 기상 데이터로 예측하는 자전거 대여량 분석

> 가상 자료 · 기능 연습 예시 · 공개 검토 확인본

작성: 데이터 탐정단

## 1. 탐구 질문
시간과 날씨가 주어지면 대여량을 얼마나 잘 추정할 수 있을까?

## 2. 데이터 출처와 범위
- 출처: 수업용으로 생성한 공공자전거 가상 자료
- 주소: 외부 출처 없음
- 이용 조건: 수업에서 활용·수정 가능. 실제 도시의 관측 통계로 인용하지 않기.
- 범위: 가상 도시, 2024-04-01~2024-04-30, 720시간. 오류와 중복을 넣은 정제 연습용 723행.
- 읽은 행 723 → 정제 후 720

## 3. 정제 이유
이상치 수준의 기상 기록과 데이터 정제 과정에서 중복된 행을 제외하여 머신러닝 예측의 일관성을 높였습니다.

## 4. 그래프와 해석

### 요일구분별 대여량 개수 비교
요일구분에 따른 기록 수를 비교한 결과, 평일과 주말 모두 비슷한 수준의 기록 수를 기록하였다. 집계표 기준 평일 기록 수와 주말 기록 수는 균등하게 분포되어 있다. 하지만 단순한 기록 수(데이터 개수) 비교이므로 요일별 실제 대여량 합계나 평균의 차이는 이 그래프로 직접 비교할 수 없다.

사용 720행 / 빈값 제외 0행. 범주별 기록 수를 함께 확인하세요. 합계와 평균은 다른 질문입니다.

### 기온 × 대여량: 함께 변할까?
기온과 대여량의 관계를 보면 기온이 상승할수록 대체로 대여량도 함께 증가하는 양의 상관관계가 관찰된다. 예를 들어 기온이 15도 이상일 때 대여량이 300대를 초과하는 기록이 많이 분포한다. 그러나 기온이 높다고 해서 무조건 대여량이 늘어나는 것은 아니며 강수 여부나 바람 등의 다른 기상 조건이 복합적으로 작용했을 가능성이 있다.

유효 718행 중 718개 점 표시(1,500개 초과 시 고정 무작위 표본). 관계는 원인의 증거가 아닙니다.

### 일별 대여량 평균의 변화
시간 변화(일별)에 따른 대여량 평균 추이를 보면 특정 날짜에 대여량이 크게 급감하거나 급증하는 변동성이 관찰된다. 구체적으로 특정 주말이나 비가 내린 날로 추정되는 날짜에 평균 대여량이 최저치로 떨어진다. 단, 단순히 일별 평균선만으로는 하루 중 언제 대여량이 집중되었는지 구체적인 시간대별 변화를 알기 어렵다.

사용 719행 / 날짜·값 누락 제외 1행. 관측값 없는 기간은 선으로 이어 붙이지 않습니다.

## 5. 머신러닝
과제: 회귀 / 정답: 대여량

입력: 시간, 기온, 습도, 풍속, 강수량, 요일구분, 날씨

시간순 분리(서로 다른 시점 기준 앞 약 80% / 뒤 약 20%), 학습 575행, 시험 144행

| 방법         |      MAE |      R2 |
|:-------------|---------:|--------:|
| 평균 기준    | 116.656  | -0.0001 |
| 의사결정나무 |  43.1017 |  0.8529 |

AI의 평균절대오차가 기준보다 작았습니다.

기본 평균값 모델에 비해 의사결정나무 모델이 시점 및 온도 변화를 유연하게 반영하여 예측 성능이 고도화되었습니다.

## 오류에서 배운 점
일부 급격한 소나기나 한파 등의 기상 변동 상황에서는 예측 오차가 커지는 트리 모델의 한계를 확인했습니다.


## 결론
기온이 올라갈수록 자전거 대여량이 크게 증가하며, 평일과 주말 모두 고르게 대여 수요가 나타납니다.


## 수치 근거
기온과 대여량의 상관계수는 양의 상관을 보이며, 머신러닝 모델(AI)의 예측 오차(MAE)가 평균 대비 약 300대 이상 감소하였습니다.


## 한계
한 달간의 데이터로만 진행되어 계절적 변화(봄, 여름, 가을, 겨울)에 따른 장기적인 수요 패턴을 반영하지 못했습니다.


## 다음 질문
강수량이나 풍속의 강도가 자전거 이용률 감소에 직접적으로 미치는 세부 임계치 구간은 어디일지 추가 분석해보고 싶습니다.
